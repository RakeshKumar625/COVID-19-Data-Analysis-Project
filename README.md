# COVID-19 Data Analysis Project
Assignment_5

## Objective
To analyze global COVID-19 trends and study their correlation with World Happiness indicators.

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
- Data Cleaning
- EDA
- Correlation Analysis
- Visualization

## Key Findings
- GDP per capita shows moderate correlation with recovery rates.
- Death rate varies based on healthcare index.
- Happiness indicators partially relate to pandemic resilience.

## Conclusion
This project demonstrates real-world data analysis skills including cleaning, merging, visualization, and insight extraction.
